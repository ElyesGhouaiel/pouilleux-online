# Le Pouilleux Online

Projet M2 - Coordination Front & Back (Ynov Toulouse).

L'idée : refaire le jeu de cartes "Le Pouilleux" en version web multijoueur.
Jusqu'à 4 joueurs par partie, en temps réel via websockets.

## Stack prévue

- Backend : Node.js + Express
- Base de données : PostgreSQL (via Docker)
- ORM : Prisma
- Temps réel : Socket.io
- Frontend : React (Vite)
